# CoinWalker

## Description
Welcome to **CoinWalker**, a simple and fun 2D game made with [Godot Engine](https://godotengine.org/). In this game, you control a character that can move in four directions—left, right, up, and down—and your goal is to collect **12 coins** to win the game. It's easy to pick up and perfect for a quick gaming session!  

## How to Play
- **Move the character:**  
  - `Arrow Keys` or `WASD` to move **Up, Down, Left, Right**  
- **Objective:** Collect **all 12 coins** to complete the game.  
- **Win Condition:** After collecting all coins, you win!  

## Features
- Smooth 2D movement in four directions.  
- Collectible coins with a simple counter.  
- Clear win condition when all coins are collected.  
- Fun and easy to extend for more levels or challenges.  

## Installation
1. Download or clone this repository:  
   ```bash
   git clone <your-repo-url>
2. Open the project folder in Godot (recommended Godot 3.5+ or 4.x).
3. Open the main scene (e.g. res://scenes/Main.tscn) and press Play.
